1.0.12
- The app always installs the newest ReToon image: it reads which files
  that image has, and their checksums, from the ReToon-images repository.
  A new image no longer needs a new version of the app.
1.0.11
- The checksums of the Toon 2 image are now in files-toon2.sha256, next to
  files-toon1.sha256 for the Toon 1.
1.0.10
- The ReToon images are no longer part of the app. The app downloads the
  one for its Toon (Toon 2 or Toon 1) from the ReToon-images repository
  when you press the button, checks every file, and removes the download
  afterwards. The app itself is now small enough for a Toon 1.
- Same ReToon image as 1.0.9 (0.1.0-test8).
1.0.9
- The app also works on a Toon 1. There it keeps the original kernel in
  the second kernel partition, puts ReToon's kernel in the first one and
  restarts. Without "Always start ReToon" a later restart goes back to the
  original software, as on the Toon 2. The Toon 1 image comes with the app
  (retoon-toon1.tar.gz).
- New ReToon image (0.1.0-test8): settings page loads faster and says
  "loading" until the values are there; brightness changes show at once.
1.0.8
- New ReToon image (0.1.0-test7): "Check for update" and "Restart"
  buttons on the Status page of the web interface. From now on a new
  ReToon can be installed from there, without this app.
- The Status page shows what the boiler module is doing while it starts.
1.0.7
- New ReToon image (0.1.0-test6): the boiler module is found reliably
  after a start; the Toon no longer shows "no boiler module" for half a
  minute while the module is still starting up.
1.0.6
- "Always start ReToon" is off at first: after installing, ReToon runs until
  the next restart, which goes back to the original software. Switch it on
  in the ReToon web interface (Settings, System, Starting up) to keep it.
- New ReToon image (0.1.0-test5): Restart button on the info screen.
- README: what ReToon does on the Toon itself and what with Home Assistant.
1.0.5
- The thermostat's preset temperatures and week program are taken over
  from the original software (thermostat.awk).
- New ReToon image (0.1.0-test4): apps, QR code on the info screen to log in
  to the web page, the clock is set as soon as WiFi connects.
1.0.4
- Fix: WiFi did not connect after the install. The WiFi settings taken over
  from the original software began with a line ReToon cannot read, so it
  refused the whole file. Now only the networks and the country are copied.
1.0.3
- Fix: the button had to be pressed twice; the screen showed the old state
  again before the install had started.
1.0.2
- Fix: a check started while the install was busy made the install fail
  ("The third partition cannot be written").
1.0.1
- ReToon itself now comes with the app (retoon.tar.gz); nothing is downloaded.
1.0.0
- First version: sets up and starts ReToon from the original Toon 2 software.
